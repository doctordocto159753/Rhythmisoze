# Rhythmisoze Agent Skills

These skills are reusable instruction modules for AI design/frontend agents. Read the relevant `SKILL.md` before changing production UI.

- `musical-art-direction` — global visual thesis and non-generic musical art direction.
- `design-system-craft` — tokens, reusable components, Storybook and system consistency.
- `musical-interaction-motion` — tempo-aware motion and time-critical interaction.
- `threejs-audio-reactive` — meaningful Three.js/R3F spatial and audio-reactive work.
- `bilingual-rtl-ltr` — Persian/English bidi construction and QA.
- `creative-ui-holistic-audit` — local-to-global design audit and root-cause fixes.
- `audio-product-accessibility` — accessible recording/playback/audio-visual interaction.
- `visual-regression-and-design-qa` — systematic visual regression and final design QA.
